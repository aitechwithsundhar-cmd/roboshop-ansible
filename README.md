# Roboshop — Ansible Deployment ⚙️

Automated deployment of Roboshop microservices application
using Ansible playbooks — Phase 2 of the Roboshop project.

## Improvement over Shell
- Idempotent deployments
- Reusable playbooks
- 80% faster than manual Shell deployment

## Services Automated
- MongoDB, Redis, MySQL
- RabbitMQ, Nginx, Node.js
